About LinguaLens

Your AI-powered language companion for the web.

L

LinguaLens

Version 1.0.0

LinguaLens is a powerful Chrome extension that brings AI-powered language tools to your fingertips. Simply select any text on a webpage to instantly translate, analyze grammar, detect phrases, rewrite content, and much more.

Features

  • 🌐 Translate — Instant translation to 15+ languages
  • 🔍 Detect Phrase — Identify idioms, phrasal verbs, and collocations
  • 💡 Insight — Deep linguistic analysis with etymology and usage
  • ✏️ Rewrite — Get formal, casual, and concise alternatives
  • 📝 Grammar — Check and fix grammar issues
  • 📋 Summaries — Condense long text into key points
  • 💭 Detect Idea Template — Identify rhetorical patterns
  • 🔤 Detect Sentence Template — Analyze sentence structure
  • 📖 Save to Vocabulary — Build your personal word bank

Built with ❤️ for language learners and writers everywhere.
